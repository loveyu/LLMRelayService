# 2026-09-10

### 新增

- 模型元数据编辑弹窗新增“重置为自动值”操作，通过独立 `DELETE /models/:channelName/:modelId/metadata` 接口清除手动上下文和价格覆盖。
- Providers 页为已启用渠道新增渠道级和「渠道 + 模型」级最近 3 次 HTTP 状态点，用绿/黄/红分别表示 2xx/4xx/5xx，点击或 hover 可查看请求时间、HTTP code 与耗时。
- Routes 别名编辑的路由目标新增拖拽排序手柄，保存时按调整后的目标顺序写入路由。

### 变更

- 优化 Logs 桌面端表格：时间固定单行展示，来源列宽度扩大一倍，过长来源可通过 hover Tooltip 查看完整内容。

### 修复

- 修复模型元数据空表单与清除覆盖语义混用的问题：保存时至少要求一项有效数据，价格覆盖继续要求输入/输出价格成对填写。
- 修复 fallback 成功后原始 429/5xx 被最终状态覆盖的问题：持久化首次上游状态，Providers 按原渠道和模型聚合；Logs 默认仍显示最终请求，仅在“错误”筛选时显示已被 fallback 恢复的原始错误。
- 修复根目录 `npx tsc --noEmit` 的存量错误：隔离拥有独立 tsconfig 的 Console 工程，并补齐 Drizzle 条件类型、请求列表字段、ES2021 数组访问及过期 SSE 测试引用。
