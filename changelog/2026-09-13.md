# 2026-09-13

### 修复

- 修复 Rust Proxy 解析多目标模型别名时未过滤禁用渠道的问题；首选目标被禁用后会直接跳过并使用下一个启用目标，同时补充 UUID 目标引用的回归测试。
- 修复上游端口静默丢包时可能等待两轮首字节超时才回退的问题：新增独立且可热更新的 TCP 建连超时（默认 3 秒），建连失败直接尝试备用路由，不再重复相同故障地址。
- 修复 Rust Proxy 已一次性加入多个备用路由后只尝试第一个的问题，并确保实际备用尝试总数不超过 `maxFallbackAttempts`。

### 新增

- 新增按“渠道 + 上游 origin”隔离的连接故障熔断器：默认连续 2 次建连失败后熔断 30 秒，期间直接跳过故障渠道，冷却后仅放行一个 half-open 探测；策略可在 Routes 回退设置及 OpenAPI 中调整。
- Console 运行配置页新增 TCP 建连超时设置，Routes 回退策略页新增熔断开关、失败阈值和冷却时间设置。
